# 教学证据与历史记录

当前学习入口是[教材基准](教材基准.md)、[必修实验](低成本必修实验.md)和[课程目录](../目录.md)。`cases/`保存正文直接使用的少量原始结果及分析，可随教程独立阅读。

`run-results/`及带日期的训练、修复和迁移文档用于解释历史实验。它们的“当前”“正在”、盘符、GPU和数据规模均属于所记载的时点，不覆盖本版教材基准。历史记录不是从新电脑启动课程的操作顺序。

整理时删除了已在原迁移归档中保留、逐文件SHA256相同的流水线原始数据、编码分片、重复Tokenizer及未采用的样本大文件。保留了正文引用的结果摘要、原始生成、评分与性能记录。部分摘要中的绝对路径仅标识当时的来源；不要求读者取得这些被清理的文件才能完成必修实验。

`run-results/teaching-repair-20261006/pre-execution/`和`minimal-before/`看起来像旧代码副本，但仍由历史回归测试读取，用于验证修复前后的差异，因此保留为测试输入。它们不作为实际模型、训练与推理核心。

正文中标注“作者工作区记录”的路径只用于追溯，不随教程分发。当前数据和实验状态见[发布摘要](数据与实验状态.md)，完整工作区的模型、数据、检查点及未公开评测材料不在教程包内。
