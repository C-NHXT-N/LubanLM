# LubanCorpus 中文聊天训练 v2

> 历史实验记录：下面的环境、路径与进行中状态属于记录时点。当前学习顺序见[教材基准](教材基准.md)，保留范围见[历史记录说明](历史记录说明.md)。

本数据版本用于 2026-10-02 开始的 50M 中文单轮聊天能力训练。不是此前 3 万篇 Wikipedia 与 764 对 OASST 短训语料的重复命名。固定 32k Tokenizer，文件存放于 `D:\LubanLM-Data\chat-v2`。

实际来源与版本、清洗数量、Token 数和分片校验和见 [数据清单](run-results/chat-v2/data-v2.json)。本轮已读取 25 万篇中文 Wikipedia 原始文章，预训练训练集为 232,861,902 Token，验证集为 4,828,786 Token；这表示语料库存，并非模型已经读过的训练量。

Wikipedia 使用 `wikimedia/wikipedia` 的 `20231101.zh` 固定 revision `b04c8d1ceb2f5cd4588862100d08de323dccfbaa`，遵循来源 CC-BY-SA 3.0 / GFDL。保留原验证文章，按内容哈希划分新增文章，NFC 清洗与精确去重。没有执行全语料近似去重。训练文章以 EOS 分隔，允许跨文章注意力。

SFT 来源包括 OASST1 中文人工审阅问答、[BELLE train_0.5M_CN](https://huggingface.co/datasets/BelleGroup/train_0.5M_CN) 合成指令问答和自建基础教学样本。OASST 沿用原始树划分与来源版本；BELLE 固定 revision `29c35e9b56c7fc91f04a613ed33896f7a19bad54`，来源数据卡标注 GPL-3.0，并附有使用限制。本轮仅本地实验，保留来源记录，不据此确定公开发布许可。

自建候选 1,000 条：600 条按规则生成并精确核算的算术样本、300 条事实模板变体、100 条聊天模板变体。它们不是 1,000 条独立人工创作样本。模板基干由本项目审阅，变体及实际清洗保留量有记录。

处理后 SFT 训练 50,536 组、验证 1,019 组，训练输入 6,057,826 Token、回答监督 2,670,322 Token；验证输入 123,713 Token、回答监督 55,672 Token。上述为单次数据编码量，不含训练时重复 epoch 或 batch padding。

按规范化问题去重与分组划分；同文开发题、验收题及额外基础检查题排除。问题划分检查、排除数与来源见 [SFT 清单](run-results/chat-v2/sft-v2.json)。未声称所有近义问题或基础答案与训练数据完全隔离。真实能力验收见 [训练闭环](50M聊天训练闭环.md)。

2026-10-03另建sft-v6，使用prefix-stable-v1编码、独立语义记录及问题/抄写负载家族隔离。训练30,299、验证1,749；祖先权重曾见过部分后移验证样本，验证不冒充独立能力测试。新清单与问题审计见 [问题分析与修正](50M问题分析与修正.md)。旧v2-v5不覆盖。

v7在v6之上按训练侧审计筛除3558条公共任务，保留26,890训练与1,600验证，公共训练18,351条。清洗不等于剩余样本全部事实正确；见 [公共语义审计](run-results/chat-v2/public_semantic_audit.json) 与 [v7清单](run-results/chat-v2/sft-v7.json)。
