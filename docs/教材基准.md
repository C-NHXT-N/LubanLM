## 统一运行位置

下载教程后保留一个工作区作为父目录。以下命令均从该工作区进入 `LubanLM/` 后执行，除非代码块明确写WSL或板端。工作区可以位于其他盘符。

```powershell
Set-Location C:\Lab\LubanLM-lab\LubanLM  # 改成自己的教程目录，仅此处需要本机路径
. .\scripts\workspace_env.ps1
$workspace = Split-Path -Parent (Get-Location).Path
$nativePython = Join-Path $workspace '.conda\lubanlm-py311\python.exe'
$qwenPython = Join-Path $workspace '.conda\qwen-py311\python.exe'
```

上面的解释器是作者目录约定；新读者先按[必修实验](低成本必修实验.md)创建自己的环境，或按[完整环境说明](新电脑环境复现.md)复现作者环境。环境脚本只设置路径，不安装软件。使用 `& $nativePython` 或 `& $qwenPython` 明确选环境；训练Qwen时选独立的 `qwen-lora-py311`。不再使用带旧盘符与GPU UUID的 `environment.ps1` 启动正文实验。

源码在教程目录，数据在父目录 `datasets/`，结果在 `runs/`，模型在 `models/`，导出在 `exports/`，报告在 `reports/`。原生50M运行数据默认指向 `datasets/general-10b-teaching-v2`；这份历史大数据不随分享包提供。小实验在自己的输出目录内生成全部输入和产物，独立于它。

## 模型和检查点从哪里来

必修小模型从随机初始化开始，无需外部权重。第7章真实分词实验只需上游Qwen3.5-2B的分词与配置文件，使用上述固定revision，不能混用其他版本的模板。完整PC推理才需权重；官方来源为 `Qwen/Qwen3.5-2B`，对照为 `Qwen/Qwen3-4B-Instruct-2507`。现有[下载器](../scripts/prepare_qwen_models.py)已固定revision，并逐文件核对来源、大小和摘要；在作者的实体WLAN下载设置下可只取2B：

```powershell
& $qwenPython -m scripts.prepare_qwen_models --model Qwen/Qwen3.5-2B --tokenizer-only --report ..\reports\reader-qwen-tokenizer
```

该入口需要[实体网络约定](新电脑环境复现.md)中列出的Windows适配器与依赖；不是任意网络上的通用安装器。上述命令只下载文本分词与配置文件，清单标为tokenizer-only；去掉该选项并改用新报告目录才获取完整2B权重。完整下载还要求模型大小外预留30GiB磁盘，Tokenizer模式额外预留100MiB。迁移电脑可通过上游固定revision获取同一快照，使用下载清单核对，勿退回可变的main。文件放入 `../models/Qwen/Qwen3.5-2B/`。

适配器必须与训练时固定的基座revision、Tokenizer、配置和目标层对应；不能拿另一基座或50M加载器打开。作者历史50M与失败LoRA没有在本版提供公开下载地址。需要这些检查点的命令标为历史研究；读者用小实验完成保存/恢复，用随书原始记录完成分析。不要把缺失权重当成需要自行寻找的隐含作业。

精确包清单、转换兼容差异及原始结果索引见[环境记录](../ENVIRONMENT.md)、[双模型实测](Qwen双模型RK3576实测.md)、[2B教学案例](cases/2B任务适配分析.md)。本版没有新增正式任务训练或发布合格模型。
