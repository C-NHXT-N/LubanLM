# 两个原模型的实测摘要

以下结果来自2026-10-18的原模型实验，未进行任务LoRA。来源为作者工作区 `reports/qwen-comparison-20261018-032232/` 和 `reports/rk3576-qwen-20261018/`；完整工作区不随教程分发，本页与随书问答用于独立阅读。

|---|---|---|
