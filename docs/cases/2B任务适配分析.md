## 用同一个问题比较回答

### JSON输出边界

题号 `general-dev-015`：只输出JSON对象，字段count为10，ready为true。

原模型完整输出：

````text
```json
[{"count": 10, "ready": true}]
```
````

微调后完整输出：

```text
{"count":10,"ready":true}
```

原模型给出了正确字段，却把对象包成数组并加上Markdown代码围栏，违反“只输出JSON对象”。微调后直接输出对象。这支持严格格式有所改善，不足以证明新知识增长。

### 关系排序

题号 `general-dev-020`：小林比小周高，小周比小吴高。只输出最高者的名字。

原模型完整输出：

```text
小周
```

微调后完整输出：

```text
小林
```

这题原模型答错最高者，微调后答对；与格式题不同，它至少在这个输入上修正了内容。还需要不同人物、不同关系与独立题来检验是否泛化。

### 格式正确仍可算错

题号 `general-dev-038`：只输出43减去17的结果。

原模型完整输出：

```text
16
```

微调后完整输出：

```text
16
```

两者都简短且遵守只输出数字，但43−17应为26，实际都输出16。训练loss下降与其他题提高，没有解决这道算术题。
