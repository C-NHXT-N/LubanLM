验证默认读取 8 个固定批次，不是全量验证集。输入 Token 计数含 SFT padding；监督位置不包含问题及 padding。训练段耗时包含循环中的校验/保存及最终保存，初始化另计入累计预算。

Base 目标 8,000,000 Token，实际 8,001,536，停止原因 `step_target`；未完整遍历全部语料。平均训练段输入速度约 5909.08 tokens/s。

0.5B 488,964,864 参数，序列 256、微批次 1、累积 4、BF16、Block 检查点。预热 3 步，计时 10 步：590.41 tokens/s；峰值分配 8527.09MiB，峰值保留 8738.00MiB。随机 ID 仅测性能。

按短基准速度线性外推：24h 约 51.01M Token；36h 约 76.52M Token；48h 约 102.02M Token。不保证长期运行维持该速度。
