## 本轮修复

- JSON 原子保存改用流式 json.dump，避免生成一份与整个候选池同样大的字符串。
- 对话候选、去重索引、文件行游标、选择状态改为磁盘 SQLite；每 2,048 个原始记录事务提交。保留原始下载文件，不重新下载。旧的 126,481 条候选流式迁移到审计存档；由于原始会话标识和上下文去重规则变化，相关原始记录需要重新筛选，存档不冒充新规则下已合格的候选。
- 原始会话用来源、固定 revision、文件及行号标识。相同问候开头的不同会话不再直接合并；一个原始会话的多个前缀只选一个。完整上下文精确去重、原始会话族和近似问句索引先于划分执行。
- 修正自然身份询问与问候识别。来源类型作为辅助，明确的概念问题不会因为位于 everyday 文件而计为日常聊天。
- 算术使用受限 AST 和 Fraction 校验完整表达式，包括括号、运算优先级和除零；显式答案冲突不能通过，不再取回答的最后一个数字。未经支持的算术不计为已验证算术；经过完整验证的纯算术不会因中文字符占比偏低被误删。检查多轮上下文中早先的错误算术。
- 硬门槛保持 100,000 训练、5,000 验证、1,000 测试独立会话；日常至少 50%、概念至多 30%，Belle 至多 25%、Alpaca 至多 20%。问候、身份和算术按合格供应量选择，取消固定缺额阻塞；优先保留稀缺的真实任务，避免被大量日常/概念记录挤掉。验证/测试覆盖按实际独立样本数分层，不足的小类报告无独立评估覆盖。
- 预训练与 SFT 的数据规则身份分开。旧规则快照与新预训练规则 AST、来源配置、tokenizer 及冻结测试定义一致，允许复用已提交 tokens；SFT 或监督程序更新不再使预训练断点失效。
- SQLite backup API 备份预训练数据库，重新逐一验证 1,032 个分片 SHA256、长度和总数，再事务迁移规则身份。保留 2,010,330,109 训练 tokens 和 8,814,677 验证 tokens；原 2B Base 与历史 GPU 账本哈希保持不变。
- 下载保留可恢复的 partial 和预取文件，缓存预订计入已经驻留的数据，不再因普通退出清空未提交下载。继续使用国内镜像入口，HTTPS socket 绑定 WLAN 物理接口，禁止代理和虚拟网卡回退。
- CPU 准备改为预训练语料、SFT 语料串行；工作进程检查 RAM/RSS/磁盘余量。SFT RSS 上限 3 GiB；系统内存不足或磁盘触及 20 GiB 保留线时停在安全断点。
- 控制器每 10 秒记录进程身份、子进程和心跳。独立 Windows 计划任务每 5 分钟、当前用户登录后检查控制器，恢复死亡进程，接管仍存活的孤立工作进程，避免重复作业；没有进展的重试最多 3 次。数据错误、缺额、内存错误和时间用尽会记录等待修复状态。
- GPU 总账保持 106 小时上限，预训练 96 小时、SFT 8 小时按已花费阶段时间扣减；CPU 准备累计预算单独记录。SFT 存在未完成 summary 时继续恢复，已测定的 batch 不在恢复时重新选择。
- 准备完整真实语料后，会用实际 FullPassTokens 读取路径重新进行 100 步 batch 24/32 副本测速。旧短测约 1.44 亿 tokens/小时、追加 10B 纯训练约 69.3 小时，仅为目前估算；准备、完整验证、定期保存、微调和评估另计。
