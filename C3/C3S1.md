```python
import torch
from torch import nn

# 一个样本、五个位置、每个位置四个特征。
x = torch.randn(1, 5, 4)
print(x.shape)  # torch.Size([1, 5, 4])
```

它就是 C2 的微型外部形状 `[B=1,T=5,H=4]`。随机数只用于走通运算，不代表具体 Token 的语义。一个 Block 先处理注意力分支，再处理前馈分支，两次都把结果加回原表示：

```text
x → 输入归一化 → Attention → 加回 x，得到 u
u → 第二次归一化 → SwiGLU  → 加回 u，得到 y
```

先看输入归一化的代码。每个位置的四个特征分别平方，再沿最后一维求平均：

```python
values = x.float()
mean_square = values.pow(2).mean(dim=-1, keepdim=True)
normalized = values * torch.rsqrt(mean_square + 1e-6)
print(mean_square.shape)  # torch.Size([1, 5, 1])
print(normalized.shape)   # torch.Size([1, 5, 4])
```

`dim=-1` 表示最后的特征维；`keepdim=True` 保留一条长度为 1 的轴，使每个位置自己的均方值能够作用于它的四个特征。这种自动对齐叫广播：大小为 1 的维度可扩展以匹配对应维度。`rsqrt` 计算平方根的倒数，因此乘它等于除以均方根。

完整 RMSNorm 还乘一条可训练缩放向量 γ，公式与 C2 相同：

$$
\operatorname{RMSNorm}(x)=\frac{x}{\sqrt{\frac{1}{H}\sum_{j=1}^{H}x_j^2+\epsilon}}\odot\gamma.
$$

这里公式的 x 指单个位置的 H 维向量，j 遍历其特征；ε 防止零分母，`⊙` 是逐元素相乘。独立算例 `[3,4]` 在 γ 全为 1、忽略 ε 时仍得到约 `[0.8485,1.1314]`。代码中的 `RMSNorm` 类用 `nn.Parameter` 登记 γ，使 PyTorch 知道它需要训练。均方和乘法先以 float32 计算，再转回输入类型。Block 的两个 Norm 各有 H 个参数，Q/K Norm 各有 d 个，参数互不共享；本章统一取 `eps=1e-6`。

归一化后的隐藏向量交给三个 Linear 层，生成 Q、K、V。Linear 对输入最后一维做线性投影，前面的样本轴、位置轴保持不变。接着使用刚才的 x，先观察投影与拆头：

```python
n_q, n_kv, d = 2, 1, 2
q_proj = nn.Linear(4, n_q * d, bias=False)
k_proj = nn.Linear(4, n_kv * d, bias=False)
v_proj = nn.Linear(4, n_kv * d, bias=False)
q, k, v = q_proj(x), k_proj(x), v_proj(x)
print(q.shape, k.shape, v.shape)  # [1,5,4]、[1,5,2]、[1,5,2]

# 先拆出头轴，再把头轴移到位置轴前面。
q = q.view(1, 5, n_q, d).transpose(1, 2)
k = k.view(1, 5, n_kv, d).transpose(1, 2)
v = v.view(1, 5, n_kv, d).transpose(1, 2)
print(q.shape, k.shape)  # [1,2,5,2]、[1,1,5,2]
```

`view` 只重新解释排列好的数字属于哪些维度，元素总数不变；`transpose(1,2)` 交换头轴和位置轴。Q 用来查询，K 供匹配，V 提供汇总内容，其数学关系仍为：

$$
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V.
$$

PyTorch 按 `[输出维,输入维]` 保存 Linear 权重，所以 `q_proj.weight` 的形状是 `[n_q*d,H]`，对应上述行向量公式中矩阵的转置。一般形状可以按同样方法追踪：

|张量|投影后|拆头并转置后|
|---|---|---|
|Q|`[B,T,n_q*d]`|`[B,n_q,T,d]`|
|K、V|各为 `[B,T,n_kv*d]`|各为 `[B,n_kv,T,d]`|

换成 50M 的 `H=512,n_q=8,n_kv=2,d=64`，输入 `[2,5,512]` 会得到 Q `[2,8,5,64]`、K/V `[2,2,5,64]`。初始化时先检查 `H=n_q*d`、头数可整除和 d 为偶数，避免运算到一半才发现配置错误。

拆头之后，完整代码先对 Q、K 的最后 d 维分别做 RMSNorm：

$$
\widehat q=\operatorname{RMSNorm}_{d}(q),\qquad
\widehat k=\operatorname{RMSNorm}_{d}(k).
$$

每个位置、每个头单独计算尺度；所有 Q 头共用一条 d 维缩放参数，所有 K 头共用另一条。张量形状不变，V 不参与。接着只旋转 Q、K，将位置关系带入点积。

本实现把头维分成前后两半，将两半中对应坐标配对。例如 d=4 时，配对的是下标 `(0,2)`、`(1,3)`。第 m 个位置的一对坐标按下式旋转：

$$
\begin{bmatrix}x'_1\\x'_2\end{bmatrix}=
\begin{bmatrix}\cos(m\theta)&-\sin(m\theta)\\
\sin(m\theta)&\cos(m\theta)\end{bmatrix}
\begin{bmatrix}x_1\\x_2\end{bmatrix}.
$$

θ 在公式中是这一对坐标的频率；代码配置 `rope_theta=1,000,000` 则是生成全部频率所用的 base，两者不要混读。位置 0 的角度为 0，后续位置按各对频率改变角度。`RotaryEmbedding` 生成 `[1,1,T,d/2]` 的 cos/sin，`apply_rotary_pos_emb` 再扩展到 d 维并广播到各样本、各头。位置必须对应 T 轴，不能只看“广播没有报错”就认定配对正确。

接着处理 GQA 分组。微型例子只有一个 KV 头，两个 Query 头都读取它；50M 有两个 KV 头，每个被四个 Query 头共享。代码用 `repeat_interleave` 在头轴上展开 K/V，微型形状就从 `[1,1,5,2]` 变成 `[1,2,5,2]`。它让后面的矩阵乘法容易读懂，但会实际复制张量；更高效的实现可以直接处理分组。

头数对齐后，用 Q 的各行与 K 的各行计算点积，除以 `√d`。省略样本和头轴，单头分数为：

$$
S=\frac{QK^\mathsf{T}}{\sqrt d},\qquad S\in\mathbb R^{T\times T}.
$$

完整分数形状是 `[B,n_q,T,T]`，倒数第二维是 Query 位置，最后一维是 Key 位置。前面的微型形状得到 `[1,2,5,5]`，因为每个头的五个 Query 都要与五个 Key 匹配。

以下保留一个只演示分数与遮罩的独立三维算例，不执行 RoPE，也不采用这个 d 构建完整 Block。取 `T=3,d=3`，Q=K 为单位矩阵，缩放后为：

$$
S=\begin{bmatrix}0.5774&0&0\\0&0.5774&0\\0&0&0.5774\end{bmatrix}.
$$

随后屏蔽 `j>i` 的未来位置：

$$
S_{ij}^{\mathrm{masked}}=\begin{cases}S_{ij},&j\le i\\-\infty,&j>i.\end{cases}
$$

第一行只保留位置 0，Softmax 权重为 `[1,0,0]`；第二行允许前两个位置，权重约为 `[0.3595,0.6405,0]`。完整程序用 `tril()` 创建 `[T,T]` 的下三角布尔遮罩，广播到所有样本和头，将禁止位置填为当前浮点类型的极小值，再沿 Key 轴执行 `softmax(dim=-1)`。这是负无穷遮罩的数值实现；本章 float32 分数范围内，被遮住位置的指数会下溢为零。填成 0 则不行，因为它仍有非零指数。

注意力权重再与 V 相乘，得到 `[B,n_q,T,d]`。代码先把头轴放回位置轴之后，再合并头：

```python
# 示意 attention_output 已由完整注意力计算产生。
attention_output = attention_output.transpose(1, 2).contiguous()
attention_output = attention_output.view(batch_size, sequence_length, hidden_size)
output = self.o_proj(attention_output)
```

这是 `LubanAttention.forward` 的片段，变量来自完整方法，不可单独运行。`contiguous()` 按转置后的次序整理内存，供 `view` 合并维度；直接对不连续的张量调用 `view` 可能报错。微型输出从 `[1,2,5,2]` 回到 `[1,5,4]`，50M 则从 `[2,8,5,64]` 回到 `[2,5,512]`，输出投影后仍可与输入相加。

当前实现显式保存 `[B,n_q,T,T]` 分数矩阵，并在 float32 中计算分数与 Softmax，再把权重转换为 V 的类型。它便于观察计算，但 T 增大时内存开销按 T 的平方增长；没有使用 FlashAttention 等融合内核，遇到内存不足时应先检查批量和序列长度。

Attention 输出加回输入后，得到中间表示 U。接着的 `LubanMLP` 分别执行 gate、up 投影，用 `F.silu` 处理 gate，再逐元素相乘并经过 down：

$$
g=XW_{gate},\qquad u=XW_{up},\\
z=\operatorname{SiLU}(g)\odot u,\qquad
\operatorname{MLP}(X)=zW_{down}.
$$

这里 X 是送入 MLP 的张量，公式中的小写 u 是 up 支路，与 Block 中间表示 U 不同。输入 `[B,T,H]` 在两条支路变成 `[B,T,I]`，down 再回到 `[B,T,H]`；所有位置用同一组权重，位置之间不在这一步混合。微型例子的 I=6，因此 gate/up 是 `[1,5,6]`。若忘记 down，I 维输出就无法按设计加回 H 维残差。

最后把模块连接成 `LubanBlock`，与 C2 的两条残差公式一致：

$$
U=X+\operatorname{Attention}(\operatorname{RMSNorm}_1(X)),\\
Y=U+\operatorname{MLP}(\operatorname{RMSNorm}_2(U)).
$$

第一条旁路保留 X，第二条保留已经更新的 U。实际张量相加可概括为下面的结构伪代码：

```python
u = x + attention(norm1(x))
y = u + mlp(norm2(u))
```

到这里，一个 Block 的外部接口保持不变。若矩阵乘法报尺寸错误，先看 Linear 接收的最后一维；若 `view` 报错，检查元素总数及转置后的连续性；若残差不匹配，检查拼头和 down；若未来影响过去，检查遮罩的行列与 Softmax 轴。[下一节](C3S2.md)会用同一套 Block，接上输入查表和输出头。
