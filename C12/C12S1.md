# 12.1 整理模型和数据说明

> 2026-10-19实验更新：成熟模型数据、基线、LoRA实现与两组正式训练已有实测记录；开发质量门槛未通过，未生成可交付合并或量化模型。本轮板端SSH认证失败，未运行新候选。

发布时先说明每份模型怎样得到。50M是本项目随机初始化训练的教学模型；成熟模型的知识主要来自上游训练，本项目提供任务LoRA；合并模型与量化模型又是不同交付阶段。把它们统称为“本项目从零训练的聊天模型”会掩盖来源。

| 交付 | 必须说明 | 当前状态 |
|---|---|---|
| 50M Base及历史SFT | 配置、32K词表、5B预训练、SFT设置、真实失败和限制 | 权重与记录已迁移；可靠通用问答未获证明 |
| 成熟模型任务LoRA | 上游标识及revision、数据、适配层和训练设置 | 两组训练各125步；1e-4最高任务语义通过率23%，5e-5必要条件筛查上界25%，均未达80%门槛 |
| 合并与量化模型 | 原模型与适配器版本、合并校验、量化配置和误差 | 未进入；未选择候选，防止将未达标结果包装成交付模型 |
| RK3576应用 | 实际硬件、系统、Runtime、驱动、实测质量与性能 | 原Qwen3.5-2B与Qwen3-4B短测已有记录；新助手板端未验收，LubanCat-3 SSH认证失败，鲁班猫4待测 |

Model Card应分别列已完成实验、未验证能力和使用限制。50M参数少是可能的限制之一，数据分布、监督目标、训练量与解码也应分析。成熟模型的任务正确率改善不意味着所有通用能力都改善，量化前后还需独立对照。

Dataset Card登记来源、版本、许可证、清洗和划分规则、样本与有效监督Token数量、事实审阅范围及已知偏差。校准文本只用于量化统计，不能把验收答案混入训练或用验收集挑量化配置。模型、任务数据、教学素材各自的许可分别核实，不由模型许可证自动覆盖其他材料。

旧 [50M Base卡](../docs/ModelCard-50M-Base.md) 与 [50M Chat卡](../docs/ModelCard-50M-Chat.md) 按历史记录保存。当前路线和已知证据边界以 [项目状态](../PROJECT_STATUS.md) 为准；没有实测记录的栏位保留待验证，不补写理想结果。
