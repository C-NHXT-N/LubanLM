# 12.2 整理项目代码与产物

目录、模型与环境采用[教材基准](../docs/教材基准.md)。历史实验保留独立名称，正文入口与当前状态分开维护。

教学章节帮助读者按顺序理解，工程目录让跨章逻辑只维护一份。50M的手写模型与原生训练器继续保留，成熟模型使用上游模型类与配套Tokenizer；两条路径可以共享评测方法和数据治理原则，但不能强行共用不兼容的权重加载器。

| 位置 | 内容 |
|---|---|
| 教程内 `model/`、`training/`、`sft/`、`inference/` | 已有LubanLM原生实现及50M历史入口 |
| 教程内章节 `program/`、`configs/`、`docs/` | 实际存在的程序、配置、教学证据与说明 |
| 工作区 `datasets/`、`runs/` | 数据版本、各实验适配器、检查点与训练状态 |
| 工作区 `exports/`、`reports/` | 合并与转换候选、评测和板端性能记录 |
| 工作区 `archives/` | 原工作树、Git历史、修订前备份和分享包 |

成熟模型入口位于 `scripts/linux_assistant/`，明确输入是原模型目录、适配器还是合并目录，不能复用原生50M的 `--checkpoint` 后仅替换路径。已有代码、已执行流程和质量验收分别记录；未通过的候选不生成交付包。

模型文件和输出放在工作区，教程源码集中于 `LubanLM/`，避免打包时混入几GB权重。教程引用的历史证据保留相对链接；新运行在独立目录记录。打包工具见 [package_tutorial.ps1](../scripts/package_tutorial.ps1)，它生成教程ZIP和SHA256，不代替完整数据与检查点备份。

第2章0.5B候选JSON和旧基准仍保留以便复算，但已经退出必修训练路线。50M扩容也另建实验，不覆盖已有检查点；真正产生新实现后再更新接口说明与代码清单。
