# 9.2 合并模型的标准目录与转换

PEFT适配器只保存增量。板端部署需要把增量合入同一固定基座，再交给语言分支转换流程。使用[合并入口](../scripts/linux_assistant/merge.py)，不要用50M的参数映射改写Qwen。

在教程目录加载统一路径，选择独立训练解释器。以下是有合格候选后的扩展流程；当前历史任务模型未达门槛，必修读者不执行合并：

```powershell
. .\scripts\workspace_env.ps1
$assistantPython=(Resolve-Path ..\.conda\qwen-lora-py311\python.exe).Path
& $assistantPython -m scripts.linux_assistant.merge
```

入口拒绝未通过开发门槛的候选，也拒绝覆盖已有合并目录。它在20个独立开发场景上比较合并前与保存重载后的下一Token分布，记录最大logit差、JS散度和首选Token变化。每题JS不超过0.001、至少19题首选相同才继续；BF16舍入不要求逐位一致。随后完整生成140道开发回答，必须重新评审。

通过后在WSL中进入同一教程目录，使用独立转换解释器；以下展示历史v1任务目录的交接，不能假设这些合并文件已存在：

```sh
~/.venvs/lubanlm-rkllm-gpu310/bin/python scripts/convert_qwen_rk3576.py \
  --model Qwen3.5-2B --device cuda \
  --model-dir ../exports/linux-assistant-v1-20261019/merged \
  --calibration ../exports/linux-assistant-v1-20261019/data_quant.json \
  --output-dir ../exports/linux-assistant-v1-20261019/rk3576 \
  --report-dir ../reports/linux-assistant-v1-20261019
```

这是一条有前置门槛的复现命令，不代表本轮已经产生合格模型。源文件摘要、运行参数、日志和完成标志保存在本轮转换报告，原模型量化文件保持独立。停止ID同时保留原生助手结束与文本结束，避免把模板尾部当成回答。
