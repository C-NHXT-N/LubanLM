# 附录 A：深度学习基础

这一附录从两个输入数开始，连接张量、矩阵乘法、梯度、反向传播和交叉熵。所有数值都能由 [basics.py](../scripts/basics.py) 复算；它使用 CPU，不需要占用训练 GPU。

在项目根目录运行 `python -m scripts.basics`，先看 `x=[[1,2]]`。张量（Tensor）就是按形状组织的一组数。`[1,2]` 的形状是 `[2]`，而 `[[1,2]]` 是 `[1,2]`，多出来的一维表示有一行。模型中 `[B,T,H]` 的三个维度分别表示序列条数、每条的位置数、每个位置的特征数。

形状不是装饰。两条序列、每条三个位置、每个位置四个特征，就有 `2×3×4=24` 个数。相同 24 个数可以重新排成不同形状，但必须保持每一维对应的含义，不能因为乘积相同就交换 batch 和时间。

接着给输入一张权重矩阵：

```python
import torch

x = torch.tensor([[1., 2.]])
w = torch.tensor([[2., 0.], [1., 3.]], requires_grad=True)
y = x @ w
print(y)  # [[4., 6.]]
```

输入为 `[1,2]`，权重为 `[2,2]`，中间两个尺寸相同，所以可以相乘。第一个输出是 `1×2+2×1=4`，第二个输出是 `1×0+2×3=6`。每个输出都取输入行与权重某列逐项相乘后相加，这个“逐项乘再求和”就是点积。

PyTorch `nn.Linear` 按 `[输出维,输入维]` 保存权重，因此实际前向常写作 `x @ weight.T`，其中 `.T` 是转置，把行列交换。课程手算常用 `[输入维,输出维]` 的矩阵，两种写法元素数量相同，但读代码时要辨明储存方向。

现在希望输出之和接近 8，当前 `4+6=10`，差值是 2。人为定义平方损失 `(10-8)²=4`：

```python
loss = (y.sum() - 8)**2
loss.backward()
print(w.grad)  # [[4., 4.], [8., 8.]]
```

梯度表示一个参数稍微变化时，损失大约怎样变化。这里平方损失对总和的导数是 `2×(10-8)=4`；权重第一行的元素乘在输入 1 上，所以对应梯度是 `4×1=4`，第二行乘在输入 2 上，所以是 `4×2=8`。梯度不是输出特征，也不是参数的新值。

反向传播沿计算依赖逐段应用链式法则。`Autograd` 是 PyTorch 记录依赖并自动求导的机制，`requires_grad=True` 让权重进入这个过程。`backward()` 将梯度加到 `.grad`，连续两次调用而不清空会累加；训练中正是利用这一点进行梯度累积。真正更新参数仍需要优化器的 `step()`。

最后把平方损失换成分类任务。下一 Token 的目标是一个整数 ID，因此使用交叉熵：

```python
from torch.nn import functional as F

logits = torch.tensor([[2., 0., -1.]])
target = torch.tensor([0])
probability = logits.softmax(-1)
ce = F.cross_entropy(logits, target)
manual = -probability[0, 0].log()
print(ce, manual)
```

两种计算都约为 0.169846。softmax 将整行分数转成总和为 1 的概率，正确 ID 0 得到约 0.8438，取负的自然对数就得到损失。第 5.1 节把同一动作应用到 `[B,T,V_vocab]` 的每个位置；SFT 再让 `-100` 标签位置跳过计分。

如果 `loss` 不是一个标量，反向传播还需要明确如何组合各分量；如果中途将张量转成普通 Python 数字，计算图也会断开。报告见 [实跑结果](../docs/Windows实跑报告.md)，遇到形状或梯度问题时，可先回到这些小数值检查，再扩大到完整模型。
