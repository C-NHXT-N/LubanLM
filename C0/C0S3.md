# 0.3 三阶段开发环境

课程使用Windows、WSL和ARM64开发板三个环境。它们通过文件交接，不共享同一个Python环境或同一套二进制库。全书模型、版本和目录以[教材基准v1](../docs/教材基准.md)为准；先做[CPU必修实验](../docs/低成本必修实验.md)，再按需要准备GPU与板卡。

| 环境 | 职责 | 本轮已知状态 |
|---|---|---|
| Windows 11 + RTX 5060 Ti 16GB | 50M教学代码、成熟模型LoRA、PC推理与评价 | Python3.11独立环境、50M加载、双Qwen推理与历史LoRA保存/恢复已验证；任务能力未达标 |
| WSL2 Ubuntu 22.04.5 x86_64 | RKLLM转换与量化 | Toolkit1.3.1已导出两个原模型；GPU兼容环境偏离SDK的Torch依赖声明，保留差异与失败记录 |
| 实测LubanCat-3/RK3576，约8GB内存 | ARM64 Runtime、C/C++应用、NPU实测 | Runtime1.3.1、驱动0.9.8；两个原模型完成八题两轮短测 |
| 教程目标鲁班猫4 RK3576，8GB/64GB | 面向目标设备的独立验收 | 尚未单独验证，不能沿用LubanCat-3结论 |

作者Miniconda位于 `C:\Tools\miniconda3`，base保持原样；原生环境位于工作区 `.conda/lubanlm-py311`，Python3.11.17、PyTorch2.12.1+cu130。Qwen推理另用 `.conda/qwen-py311` 与Transformers5.8.0，LoRA另用 `.conda/qwen-lora-py311`。新读者可另建CPU实验环境，不必复制作者安装盘符。WSL转换环境独立使用Python3.10，不能把Windows环境复制过去。

从教程目录加载 `. .\scripts\workspace_env.ps1` 设置路径；它不安装依赖。数据、模型、结果和导出放在教程父目录。首次安装与网络约定见[环境复现](../docs/新电脑环境复现.md)，实际转换、内存失败及重试见[双模型实测](../docs/Qwen双模型RK3576实测.md)。本机网络过程留在实验记录，不作为所有读者必需的配置。

源文件集中在 `LubanLM/`；数据、检查点和导出目录位于它的上一级工作区。旧RTX 4060 Ti训练记录仍是历史事实，不能直接称为5060 Ti测试结果。环境详情见 [迁移环境记录](../ENVIRONMENT.md)，安装基础见 [附录B](<../附录/附录B 开发环境.md>)。
