# 10.1 板端系统、驱动与最小运行预检

实际用于2026-10-18原模型短测的是LubanCat-3/RK3576，系统为Ubuntu22.04、Python3.10，驱动0.9.8、Runtime1.3.1。目标教程中的鲁班猫4属于待验证设备，不能将这两者的验收结果互换。

在任何新板端试验开始前保存以下输出：

```sh
uname -a
uname -m
cat /proc/device-tree/model
free -h
df -h
python3 --version
```

这些输出分别检查系统与内核、进程架构、设备标识、内存、存储和解释器。设备树文件可能含末尾零字节，记录时保留原始信息。NPU设备、驱动版本和运行库还需按该板系统的实际暴露方式与固定SDK示例核验，不凭空假设某个sysfs路径存在。

已有原模型短测记录见[实测报告](../docs/Qwen双模型RK3576实测.md)。新任务模型需另行保留模型SHA、运行库SHA、加载返回码与日志。加载成功只证明这一阶段可以开始推理，不证明任务、视觉或鲁班猫4兼容性。

本轮SSH已通过旧cat公钥核对，认证未通过；这属于登录条件缺失，不可据此推断设备关机，也不通过更改代理来掩盖认证问题。新模型质量和60分钟运行均尚待实际验收。
