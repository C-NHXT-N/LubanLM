# LubanLM：从零理解大语言模型，到微调与板端部署

我希望通过 LubanLM，带你从分词和 Transformer 实现开始，亲手训练一个小模型，再学习成熟模型微调、量化和 RK3576 部署。我把原理讲解、可运行的示例和实战代码放在一起，方便你边读、边改、边观察结果。

## 适合谁学习

如果你已经掌握 Python 基础，希望弄清大语言模型怎样处理文字、怎样训练，以及怎样在自己的设备上运行，可以从第 00 章开始。接触过 PyTorch 会更容易上手；遇到张量、梯度等概念时，也可以先阅读[深度学习基础附录](<附录/附录A 深度学习基础.md>)。

## 我安排的学习路线

前半部分以一个约 50M 参数的小模型为线索，讲分词、模型实现、数据与预训练；后半部分使用成熟模型，学习任务微调、推理、量化和板端应用。你可以先在 CPU 上完成一个短小的训练实验，再根据自己的设备和学习目标深入。

## 从哪里开始

1. 先读 [00 · 项目目标与学习准备](00/README.md)，了解课程结构。
2. 按[实战项目的快速开始](project/README.md#快速开始)运行 CPU 小实验，观察训练、保存、恢复与生成。
3. 依次阅读章节，运行章内示例，再到 `project/` 中查看完整实现。

## 仓库怎么用

`00/`—`12/` 是教程正文与章内示例；[project/](project/README.md) 集中存放训练、微调、推理和部署代码；[docs/](docs/README.md) 提供环境说明、模型与数据资料、实验记录。模型权重和大型训练数据需要单独准备，具体方法见实战项目说明。
