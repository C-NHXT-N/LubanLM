# 6.2 观察语言能力怎样形成

> 2026-10-16 路线更新：50M 已完成 5B Token 预训练及一轮 SFT，作为从零训练的教学案例保留；现有结果未证明可靠通用问答能力。第7章起转向成熟模型 LoRA 微调与部署，扩容另作可选实验。当前状态见 [项目状态](../PROJECT_STATUS.md)。

> 实验入口：先完成[低成本必修实验](../docs/低成本必修实验.md)。本节大规模数据与50M命令用于历史研究，需要对应的旧数据版本；目录采用workspace_env.ps1设置，使用已激活的原生环境，不是成熟模型LoRA入口。

训练日志反映预测误差，读者还会想看到模型真正写出了什么。先固定四个开头：“Linux 是”“中国的首都是”“C语言是一种”“人工智能是”。这些提示只提供开头，不包含预设答案，也不作为临时训练样本喂给模型。

固定提示实验要控制生成方法。若随机模型用高温采样、训练后模型用 greedy，输出差异可能来自采样而不是权重。本课程对各预训练保存点采用相同 Tokenizer、相同提示、greedy 解码和最多 32 个新 Token。greedy 每次选当前分数最高的候选，细节会在第 8 章展开。

下面保留早期短训练中将计划步数约分四段的观察方法，不把示例预算当成最终训练量。迁移后的50M最终完成5B Token，实际进度以检查点内计数与项目状态为准。初始点尤其需要保留，否则只看最终模型，无法确认变化是从什么状态开始的。

## 同一提示的三份真实续写

先读随书已有记录，再决定是否自行加载历史检查点。下面三份输出均来自2026-10-02早期约8M Token实验，相同提示“Linux 是”、相同Tokenizer、greedy、最多32个新Token；不是最终5B权重的阶段对比。原始内容保留在[证据摘录](../docs/cases/50m-stages.json)，来源为随书generation_observations.json。

```text

```

`step-001952.pt`，32个新Token：

```text


在20世纪年，在20世纪年，在16世纪年，在16世纪年，在16世纪年，在16世纪年，
```

`last.pt`，32个新Token：

```text
在“一个”的，而“一个”是“一个”的，而“”是“”是“”是“”是“”是
```

随机权重已能反复选中词表片段，但“翻译家”重复不表示懂得Linux。到第1952步，出现较像自然文本的时间短语，仍循环且与提示无关；末步转成“一个”的循环，也没有解释Linux。可读片段增多、围绕问题回答、事实正确和避免循环是不同指标。这组样本不支持“训练越久，这个提示就单调变好”的结论。

早期实验固定验证loss从10.481856降到6.130860，仍有上述错误。它说明同来源文本预测改善与可靠问答之间还有距离；不能把这个8M案例的loss与最终5B训练混写。最终5B模型的记录及尚未核齐的对照范围见[历史索引](../docs/50M-SFT历史对照.md)。

以下是旧50M Base/Chat对照命令，需对应的历史检查点和旧数据版本；它不是观察Base的必修前提，也不是成熟模型的评测入口：

```powershell
. .\scripts\workspace_env.ps1
python -m eval.observe --base $env:LUBAN_RUNS\checkpoints\50m-base --chat $env:LUBAN_RUNS\checkpoints\50m-chat\last.pt
```

程序见 [observe.py](../eval/observe.py)。`generation_observations.json` 按检查点保存每个提示的真实续写、生成 Token 数和 Base/Chat 对比。初始点可能产生无法组成正常词语的字节，训练后也可能重复、答错、混合不相关事实。记录必须保留这些现象，不能用手写的标准答案替换原始输出。

Token 不一定对应完整字符。字节级 BPE 在未合并的罕见片段上可能先生成一个 UTF-8 字节，完整序列解码时才得到字符。离线观察会解码整段新 ID；流式界面则要等待字节完整，不能把单个 Token 的替换字符直接打印出来。第 8.4 节会处理这个界面问题。

阅读结果时，可以按几种具体现象做笔记：乱码是否减少，中文片段是否更连续，是否围绕提示续写，是否重复同一个句式，是否产生错误事实。这些是对当前提示的观察，不是一个覆盖全部语言能力的评分。“中国的首都是”偶然补出正确地名，也不能证明所有地理知识都已经学会。

如果同一提示的输出暂时变差，也不必立即断言训练失败。单一提示对细微分数变化很敏感，greedy 的第一步换了一个 Token，后续上下文就会完全不同。把生成样例与验证 loss 一起看，才有足够依据决定是否调整数据或训练设置。

50M 短训练可能首先学到标点、常见词和句式，具体出现哪些变化以实测记录为准。本次不预设“最终一定稳定回答问题”。下一节用未参与训练的数据与一个小型标准工具体验，补上另一种观察角度。
